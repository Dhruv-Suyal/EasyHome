🏠 EasyHome – Property Rental & Booking Platform

EasyHome is a full-stack property rental and booking web application built using Node.js, Express, MongoDB, EJS, and Tailwind CSS, with secure online payments powered by Razorpay.

The platform allows users to browse rental properties, view detailed listings, and complete secure bookings through an integrated payment gateway.

🚀 Features

🔐 User Authentication (Register / Login / Logout)

🏘️ Add & Manage Property Listings

🔍 Search & Filter Properties

📄 Property Detail Page

💳 Secure Online Payments (Razorpay Integration)

📦 Booking System

🛡️ Protected Routes & Middleware

📱 Fully Responsive UI (Tailwind CSS)

📊 Owner Dashboard for Managing Listings

Backend

Node.js

Frontend

💳 Payment Integration

Payments are securely processed using:

Razorpay

Order creation from backend

Secure checkout flow

Payment verification using signature validation

Booking confirmation after successful payment

📸 Application Flow

User registers or logs in

User browses available rental properties

Selects a property and proceeds to booking

Razorpay checkout opens

Payment verification occurs on backend

Booking is confirmed and stored in database
